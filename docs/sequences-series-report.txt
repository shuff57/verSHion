Controls (all 40 parameter keys and the example selector):
mode — Arithmetic, Geometric, Explicit f(n), or Recursive.
first — First value, absent for Explicit.
difference — Arithmetic difference, typed as a number or exact expression.
ratio — Geometric multiplier, including negative and fractional values.
formula — Typed explicit expression; ambiguous 1/2n-style spellings are refused with bracket examples.
recurrence — Typed previous-term expression; a_(n-1), a_{n-1}, a(n-1), and Unicode subscripts are accepted.
second — Second seed, shown and used only if the recurrence refers to the second previous term.
count — Number of displayed terms, 3–24.
start — Index starts at 0 or 1.
display — Terms, Partial sums, or Both; aligned graphs always show Both.
layout — One grid, Two aligned graphs, or Number line.
join — Light joins between consecutive visible marks, with gaps around text.
marks — Dots or Spikes.
point_values — Values beside marks; long values are explicitly approximate, with exact key/list values retained.
terms — Term list; hidden and inert for Missing terms, whose requested list is forced on.
sums — Partial-sum list; student sum answers are blanked whenever a sum is requested.
explicit — Written explicit formula, or a student blank. Find formula always retains a blank even with both formula toggles off; the toggle is hidden when that compulsory blank makes it inert.
recursive — Written recurrence and the actual seeds/domain, or a student blank.
sum — Finite sum of the displayed terms, general arithmetic/geometric formula, and established geometric infinity sum.
sum_n — Separately request the sum of the first N terms, independently of how many terms are drawn.
sum_count — N, 1–1000; shown only with sum_n or sigma.
sigma — Sigma notation for the current sequence, from k=start through start+N-1; expression blank on a student copy.
convergence — Derived sequence/series classification and limit; unsupported cases remain cannot determine.
limit — Established finite term/sum limit, named and dashed on a grid, named above the number line.
band — Standard L ± epsilon band, total width 2epsilon.
epsilon — Typed positive distance from L.
from — Lower vertical bound (horizontal value bound on the number line), -100 through 99.
to — Upper bound, -99 through 100; must exceed From.
step — Count by, 0.000001 through 20; all axis controls use 0.000001 increments; dense requests receive notes.
grid — None, Light, Standard, Bold; hidden on the number line.
xlabel — Index-axis name at the arrow; hidden on the number line. A long multiword name is shortened with a note (Term number becomes Term); unfitting/reserved names are omitted with a note.
ylabel — Value-axis name, with the same fitting/reserved-name rule.
title — Teacher caption, up to 48 characters.
blank_title — Blank caption line; student copies always have a blank title.
task — Find formula, Missing terms, Continue.
missing — Comma-separated requested indices; shown on student copies and keys for Missing terms; key rows mark these as asked.
given — First 1–6 terms provided for Continue; at least one term remains blank.
show_answers — Key/student copy toggle. Answer-bearing points, values, formulas, sums and descriptions obey the selected task.
style — Colour or grey-only Print.
label_size — Small, Medium, Large, with canvas and label placement scaled accordingly.
Classic examples — Arithmetic, Geometric halving, Alternating halves, Fibonacci, Reciprocals, Geometric partial sums.

5. Functions compose within the checked expression reader. Rational-angle trig identities and perfect rational squares yield exact values; other values carry approximations. Reflection identities pair trig terms so complete periods sum exactly. Factorials support the requested small-n examples.
6. Rational-function limits use polynomial degrees and leading coefficients, with exact checked coefficients. Standard identities cover (1+1/n)^n, n^(1/n), root differences, n sin(1/n), logarithmic-over-linear decay, constants and supported powers/oscillations.
