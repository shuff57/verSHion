The script now takes a lock, builds into a temp directory, renames once, and records every image's source, so verify_blind.py rebuilds all 65 byte for byte before a round starts.
How firm these are. The controls pass exactly (0.00) in rounds 4–7, so each judge is self-consistent within a round.
